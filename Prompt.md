# Prompt utilizado para gerar o frontend

Crie um frontend em React com Vite, em português do Brasil, para uma plataforma de reservas de salas universitárias. O frontend deve ter duas telas ou abas: uma para cadastrar e alterar salas e outra para consultar salas. A tela de consulta deve permitir pesquisar por nome ou bloco e oferecer ações de editar e excluir. A entidade sala possui nome, bloco, capacidade, lista de recursos e disponibilidade. Consuma uma API REST configurada pela variável VITE_API_BASE_URL com os endpoints POST /api/salas, GET /api/salas?q=termo, PUT /api/salas/:id e DELETE /api/salas/:id. Mostre estados de carregamento, mensagens de erro e sucesso, confirmação antes de excluir e uma interface responsiva, acessível e adequada para uma demonstração acadêmica.
