# Roteiro de evidências — Semana 5

Os prints devem mostrar o portal ou a aplicação real. Não use apenas o código como evidência de criação dos recursos.

## 1. Banco de dados MongoDB Atlas

Capturar uma tela no MongoDB Atlas mostrando:

- o cluster `pucpr-cluster`;
- o banco `pucpr_db`;
- a coleção `salas`;
- pelo menos um documento de sala.

A coleção `evidencia` existente também pode ser mostrada como comprovação complementar da criação do banco.

## 2. Quatro Azure Functions

Na Function App publicada, abrir a área **Functions** e capturar a lista contendo:

- `inserirSala`;
- `pesquisarSalas`;
- `alterarSala`;
- `excluirSala`.

O nome da Function App e a URL do portal devem aparecer no print, quando possível.

## 3. Frontend executando o CRUD

Capturar a interface React em funcionamento, preferencialmente com quatro registros ou prints curtos:

1. cadastro de uma nova sala com mensagem de sucesso;
2. sala alterada com os dados atualizados;
3. pesquisa filtrando por nome ou bloco;
4. exclusão confirmada e sala removida da lista.

O print deve mostrar a URL pública do Static Web App e a mensagem/resultado da operação.

## 4. Documentação

Conferir antes da entrega:

- nomes completos em `GRUPO.md`;
- link público do GitHub;
- URL da Function App;
- URL do Static Web App;
- `Prompt.md` preenchido;
- este roteiro ou os prints anexados conforme orientação da disciplina.
